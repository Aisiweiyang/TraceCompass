# 推断方法与局限

## 主题

默认字符 2–3 gram TF-IDF，稳定顺序的 leader clustering，按余弦阈值归簇并过滤小簇。
可选 embedding 接口与 TF-IDF 使用独立阈值。主题名默认由高频词片段生成；
可选 LLM 命名失败时退回关键词。父主题由簇心二次聚类生成。

主题身份来自成员签名。全量重算时，成员变化可能创建新主题并退役旧主题；
这会影响标签和合并等人工修改的延续，不具备完整的稳定增量主题跟踪。
字符相似不等于语义相同，跨语言同义内容不保证归到一起。

## 兴趣

9 个分量进入加权和：频率、新近度、持续性、深度、回访率、追问密度、项目转化、
连接度、自愿性；义务性用于类型判定。权重、阈值在 `config.toml` 显式配置。
缺失时间时重归一部分权重并降低置信度。

生命周期包括 temporary、emerging、stable、declining、dormant、reactivated。
这些是规则标签。评分依赖当前日期、文本长度和样本覆盖，不能直接推断兴趣强弱、
人格或未来行为。确定性仅指相同输入、配置和参考时间下的计算。

## 目标、项目和问题

只从用户消息用中英文规则抽取候选。显式目标与推断目标分别标记 `USER_STATED`
和 `INFERRED`。项目识别依赖命名模式；重复问题主要按归一化文本匹配，
出现至少 3 次且跨至少 2 个自然周可标为 recurring，不保证识别改写型问题。

证据引用用于检查候选来源，置信度不是经过真实标注校准的正确概率。
Meta Interest 生成、通用撤销和自动评测 CLI 尚未实现。
